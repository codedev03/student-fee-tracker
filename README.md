# 📚 Student Fee Collection Tracker

An ultra-fast, lightweight, and zero-login web application built specifically for managing student rosters and fee collections on the go, equipped with voice recognition for hands-free entry[cite: 1].

---

## ✨ Features

- **51 Pre-Populated Records**: Automatically loaded with exact student names and fee amounts (Total: ₹87,200) from physical ledger sheets[cite: 1].
- **🎤 Voice Command Input**: Seamlessly add or update student fees using speech recognition (optimized for secure HTTPS deployment)[cite: 1].
- **🔍 Instant Search & Filter**: Rapidly look up students by name or filter by payment status.
- **📊 Real-Time Analytics**: Live counters tracking total collected fees, paid student count, and pending balances.
- **⚡ Zero Setup / No Login**: No authentication, databases, or complex configurations required—works instantly in any modern browser.
- **💾 Local Storage Persistence**: All updates and additions are automatically saved locally on your device.

---

## 🚀 Quick Deploy

1. Clone or download this repository.
2. Upload `index.html` to your preferred static hosting provider (e.g., **Render**, **GitHub Pages**, or **Vercel**).
3. Access your secure live HTTPS URL to start tracking collections instantly[cite: 1]!
